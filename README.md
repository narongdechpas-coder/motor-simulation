# Motor Package Simulator

เครื่องมือจำลองการออกแบบแพ็กเกจประกันรถยนต์ภาคสมัครใจ ใส่ราคาเบี้ย ต้นทุน และ Loss Ratio แล้วระบบคำนวณว่าต้องขายกี่กรมธรรม์ใน 3 กรณี

- **Base Case** ปีที่ 1 เท่าทุน (CR = 100%)
- **Best Case** ปีที่ 1 CR ต่ำกว่าเป้า (ค่าเริ่มต้น 95%)
- **Worst Case** กำไรสะสมเท่าทุนในปีที่ 3

พร้อมเทียบ LR ที่ใส่กับ Industry เพื่อกันการใส่ค่าดีเกินจริง

**เปิดใช้:** https://narongdechpas-coder.github.io/motor-simulation/

## ไฟล์

- `index.html` แอปทั้งหมดอยู่ในไฟล์เดียว (ส่วน engine อยู่ระหว่าง `ENGINE START` / `ENGINE END`)
- `tests/engine.test.js` ทดสอบ engine กับเคสคำนวณมือ รันด้วย `node tests/engine.test.js`

ข้อมูลที่กรอกและฐานข้อมูลที่แก้ เก็บใน browser ของเครื่องที่ใช้เท่านั้น ไม่ถูกส่งขึ้นเว็บ ถ้าจะย้ายเครื่องให้ใช้ Export JSON

## สมมติฐานหลัก

- ราคาที่กรอกรวมอากร 0.4% และ VAT 7% ระบบถอดเป็นเบี้ยสุทธิก่อนคำนวณ
- คิดบน Earned Premium โดยสมมติว่าขายเฉลี่ยทั้งปี (ปีที่ขายรับรู้ 50% ปีถัดไป 50%)
- ต้นทุนผันแปร (LR, Commission, OPEX/MKT ส่วนผันแปร) รับรู้ตามสัดส่วน Earned และ Fixed cost รับรู้เต็มทุกปี
- Gross ก่อน Reinsurance ไม่คิด IBNR และรายได้จากการลงทุน
- Industry LR ค่าเริ่มต้น 59.6% (Motor ภาคสมัครใจ 9M/2567 จากข่าวที่อ้างข้อมูล คปภ.) ยังไม่ได้ยืนยันกับรายงานต้นฉบับ

## จุดที่ควรให้ผู้เชี่ยวชาญยืนยัน

- ตัวเลข Industry LR เทียบกับรายงาน คปภ. ฉบับต้นฉบับ และค่าแยกตามประเภทความคุ้มครอง
- การรับรู้ Commission ตาม Earned หรือ Written
- วิธีถอดอากรและ VAT
- สมมติฐาน Earned 50/50 และการไม่คิด IBNR / Reinsurance
